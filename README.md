- **HTML5:** Semantic structuring and web accessibility.
- **CSS3:** Advanced styling, Grid/Flexbox layouts, animations, and responsive design.

- **JavaScript (ES6+):** DOM manipulation, event handling, logic implementation, calculations, arrays, and objects (e.g., product calculation systems).
